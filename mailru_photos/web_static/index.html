ОТКУДА И КУДА ЗАГРУЖАТЬ

Исходные папки

У каждого источника своя папка в Облаке. Структура вложенных каталогов сохраняется.

Выбирайте папки на компьютере, где запущен клиент. В Docker это подключённые каталоги сервера. Файлы не передаются через браузер.

Чтобы изменить источники, приостановите текущую работу и дождитесь сохранения прогресса.

Подключите первую папку

Можно добавить несколько дисков и архивов. Структура вложенных папок сохранится в Облаке.

Планировщик

Расписаний пока нет

Выберите папки, время и дни запуска. Можно добавить несколько независимых расписаний.

Если клиент занят, сработавшее расписание дождётся своей очереди. Пропущенное время, пока сервер выключен, не запускается задним числом. Общая пауза отменяет ожидающие срабатывания, а будущие расписания остаются включёнными.

НОВЫЙ ИСТОЧНИК

Добавить папку с фото и видео

Файлы читаются прямо из этой папки. Все вложенные каталоги будут найдены автоматически.

Чтобы выбрать другую папку на сервере, уберите этот источник и добавьте новый.

Подпись в этой панели. Название не добавляется к пути в Облаке.

Полный путь от корня Облака, начиная с /. Например, файл 2024/IMG.jpg окажется в /Фото/Семья/2024/IMG.jpg.

Новое назначение применяется к будущим и ещё не отправленным задачам. Уже загруженные файлы в Облаке не перемещаются.

Изменения доступны после остановки текущей работы.

ИСХОДНЫЕ ПАПКИ

Убрать источник?

Источник и связанные с ним задачи будут убраны из очереди, включая завершённые. Файлы на сервере и в Облаке останутся на своих местах.

Папку можно добавить снова. Её задачи будут созданы заново при сканировании.

Убрать источник можно после остановки текущей работы.
