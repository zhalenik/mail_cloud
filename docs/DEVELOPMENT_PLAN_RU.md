# План развития и журнал проверок

Задачи этого цикла разбиты на последовательные выпуски. Каждый опубликованный тег сохраняется; следующий выпуск включает изменения предыдущего. Последний выпуск объединяет весь цикл. Новая версия использует существующий каталог `/state`.

## Правила поведения

- Объект очереди называется **задачей загрузки**. Исходный файл и задача — разные сущности.
- Удаление источника, задачи или очистка очереди изменяет локальное состояние приложения. Исходники на диске и файлы в Облаке не удаляются.
- Основная очередь и общий прогресс отражают актуальный результат полного сканирования. Прерванное сканирование не объявляет непройденную часть источника исчезнувшей.
- Сохранённая история подтверждений не должна превращаться в лишние активные задачи. Перенос файла не должен безусловно создавать вторую задачу для того же объекта.
- Назначение задаётся каждому источнику отдельно. Изменение назначения не перемещает уже созданные файлы в Облаке; существующие подтверждения нельзя использовать для другого пути.
- Ошибка отдельного файла видна в списке ошибок и не блокирует следующие задачи. Общая потеря авторизации, недоступность состояния и нарушение проверки квоты обрабатываются отдельно от ошибки файла.
- Пауза отдельной задачи не должна выставлять общий сигнал остановки. Пауза, удаление и перезапуск должны корректно разрешаться при незавершённом запросе к серверу.
- Файл считается успешно загруженным только после положительного подтверждения режима хранения и проверки хеша/размера. Совпадение имени или хеша существующего объекта само по себе не доказывает безлимит.
- Сверка с Облаком выключена по умолчанию, использует отдельный модуль и не подменяет подтверждения загрузки. Недоступность сверки не должна повреждать очередь.
- Выдача исходников браузеру требует входа в панель. Запрос выбирает задачу по ID, а не произвольный путь сервера. Сохраняются ограничения исходных каталогов и защита от символьных ссылок.
- Изменение пароля панели требует действующего сеанса и проверки текущего пароля, сохраняет только проверочное значение и завершает старые сеансы. Восстановление забытого пароля не должно открывать незащищённый HTTP-сброс.
- Квота отображается с временем последнего успешного измерения. Ошибка сети не заменяет реальные значения нулями.
- Обычная загрузка больших файлов в рамках этого цикла не возвращается.

## Проверки перед публикацией

Для каждого этапа: целевые регрессионные тесты, полный набор тестов приложения, проверки выпуска, сборка установленного пакета и запуск контейнера в CI. Для изменений интерфейса дополнительно проверяются реальные браузерные сценарии. Для миграций используются состояния предыдущих выпусков. Проверки больших очередей должны контролировать ограниченность памяти и стоимость выборки заданий, а не только число успешно выполненных операций.

Публикация включает неизменяемый тег версии и обновление `stable` после успешного CI. В публикуемые файлы не входят авторизация, локальное состояние, персональные пути и адреса. Живые проверки в аккаунте и автоматические проверки с тестовым сервером отмечаются раздельно.

## Журнал

### Подготовка

- Восстановлена рабочая копия опубликованного 0.4.3; подтверждён исходный коммит `6fb4900a147816c7bc6632d046de7960f6cdffa7`.
- Воспроизведена ошибка прогресса: пять существующих файлов после переноса двух дают семь записей в статистике, хотя сканер корректно устанавливает `present=0` для старых путей. Причина — включение отсутствующих записей в отображаемые агрегаты и список.
- Поддержка безлимита для видео подтверждена документацией Mail и исследованием Android-клиента. Причина отказа конкретных небольших видео пока не установлена. Выпуск 0.4.4 предназначен для проверки поведения без кода обычной загрузки, а не объявляется подтверждённым исправлением серверного отказа.

### 0.4.4 — опубликован

- Удалены production-операции обычной загрузки и переключатель больших файлов; старое включение настройки не применяется.
- Возвращены транспорт и единый цикл обработки 0.4.2, сохранено обнаружение видео и исключение файлов больше 2 ГБ.
- MP4/M4V-образцы 5 и 10 МиБ проверены локальным декодером; автоматические тесты сравнивают запросы с фотографиями. Живой сервер в этих тестах не используется.

- Выпуск: `07c47a639680f1a56d70ad8fe0a1e8a09d134835`, тег `v0.4.4`. Прошли 243 теста приложения, 19 проверок публикации, проверки установленного пакета и реального контейнера в CI. Проверка секретов не обнаружила утечек.

### 0.5.0 — подготовка выпуска

- Исправлены текущая выборка задач и агрегаты; добавлено индексированное распознавание перемещений.
- Подготовлены независимые назначения источников, изменение и удаление через панель и CLI.
- История подтверждений отделена от жизненного цикла задачи; миграция в схему 2 транзакционная.

- Выпуск 0.5.0 опубликован из `363cfba34adf9e2ebbcaa2531b3a1e378fcee54d`; проверены контейнер, обновление stable и анонимное скачивание.
