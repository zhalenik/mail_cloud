# Работа через CLI

CLI использует тот же механизм очереди и загрузки, что и браузерная панель. Для обычного использования NAS удобнее [панель](WEB_GUI_RU.md). Не запускайте CLI одновременно с панелью на одном каталоге состояния.

## Установка

Нужен Python 3.11 или новее. В корне клонированного репозитория:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
python -m mailru_photos --help
```

Команды ниже предназначены для Linux. `/srv/mail-cloud-state` и `/srv/photos` — примеры: замените их своими существующими путями. Папку состояния держите на локальном filesystem с доступом только владельца, вне каталогов сетевой или облачной синхронизации.

## Первый запуск

Выберите отдельную новую папку назначения в Облаке и создайте очередь:

```bash
python -m mailru_photos --state /srv/mail-cloud-state init --destination /PhotoArchive
python -m mailru_photos --state /srv/mail-cloud-state login --email user@example.com
python -m mailru_photos --state /srv/mail-cloud-state doctor
python -m mailru_photos --state /srv/mail-cloud-state add-folder /srv/photos --alias Family
python -m mailru_photos --state /srv/mail-cloud-state scan
python -m mailru_photos --state /srv/mail-cloud-state status
```

В `login` укажите свой адрес. Пароль внешнего приложения Mail запрашивается скрыто и не передаётся аргументом командной строки. `doctor` проверяет аккаунт, доступность режима безлимита и квоту; он не загружает файлы.

`scan` по умолчанию находит фото и видео. Параметр `--extensions jpg,png,mp4,mov` задаёт свой фильтр; он сохраняется для следующих сканирований. [Список стандартных расширений](WEB_GUI_RU.md#фото-и-видео).

Перед основной загрузкой выполните контрольную проверку:

```bash
python -m mailru_photos --state /srv/mail-cloud-state probe --count 3
python -m mailru_photos --state /srv/mail-cloud-state run --workers 2
```

`probe` действительно загружает выбранные фотографии или видео до 2 ГБ из очереди и измеряет квоту. `run` допускается после подходящей успешной проверки. Результат `provisional_pass` означает наблюдаемое подтверждение во время проверки; он не обещает будущего поведения сервиса.

CLI пропускает файлы больше 2 ГБ. Обычная загрузка таких файлов в этой версии отсутствует.

Для дополнительного источника повторите `add-folder` с другим уникальным `--alias`, затем `scan`. Чтобы найти новые фотографии или видео в уже добавленных папках, также выполните `scan`. Вложенные пути сохраняются под `/PhotoArchive/<alias>/...`.

## Основные команды

| Команда | Назначение |
| --- | --- |
| `status` | Локальная статистика, источники и результат последнего сканирования. |
| `scan` | Обход источников и обновление очереди. |
| `probe --count 3` | Контрольная загрузка и измерение квоты. |
| `run --workers 2` | Обработка очереди с двумя параллельными загрузками. |
| `errors --limit 20` | Ошибки отдельных заданий. |
| `retry-failed` | Возврат повторяемых ошибок в очередь после устранения причины. |
| `recover` | Восстановление незавершённых заданий после аварийной остановки; без сети. |
| `report --output report.json` | Сохранение диагностического отчёта. |

`--state` указывайте **до** имени команды. Полный набор параметров доступен через `python -m mailru_photos <команда> --help`.

Для остановки нажмите `Ctrl+C` и дождитесь завершения процесса. Повторный `run` использует сохранённую очередь, но может потребовать свежий `probe`. Не удаляйте состояние ради повторного запуска.

Диагностический отчёт не предназначен для безусловной публичной публикации: даже без паролей и токенов он может содержать адрес аккаунта, пути и имена файлов. Перед отправкой удалите личные данные.

## Существующая очередь и перенос

Очередь связана с аккаунтом, папкой назначения и абсолютными путями источников. Для нового аккаунта или отдельного назначения используйте отдельное состояние. Перед любым переносом остановите использующий его процесс и сохраните всю папку.

Автоматическое преобразование Windows-путей и Windows-защиты токенов в Linux пока не реализовано. Сохраните прежнее состояние и используйте [порядок переноса из инструкции TrueNAS](TRUENAS_RU.md#перенос-существующего-состояния).
