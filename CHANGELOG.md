# История изменений

Записи 0.3 и 0.4 описывают этапы разработки, перенесённые в публичный репозиторий. Они не утверждают наличие исторических Git-тегов или релизов. Даты задним числом не назначены.

## 0.4.1 — подготовка публичного выпуска

- Подготовлена упаковка Docker-образа и его публикация в GHCR.
- Добавлены версия 0.4.1, OCI-метаданные и Docker healthcheck.
- Добавлен отдельный Compose YAML для TrueNAS Docker Apps с обычным портом `31800:8787` и явными путями к dataset.
- Документированы установка, UID/GID и права, несколько фотоисточников, обновления и сохранение состояния.
- Уточнены разные назначения проверки HTTP `Host`, публикации порта Docker и `MAILRU_PUBLIC_ORIGIN`.
- Добавлены краткие события фаз работы и счётчики прогресса в журнал контейнера без адресов аккаунтов, путей файлов и токенов.
- Добавлены исключения Git для локального состояния и персональных материалов. Протокол загрузки в этом выпуске не меняется.
- Перенос существующей Windows-очереди на Linux/TrueNAS не добавлен.

Первая сборка и публикация образа должны подтверждаться фактическим результатом GitHub Actions. Эта запись не является утверждением об успешном запуске на конкретном NAS.

## 0.4 — браузерная панель

- Добавлена панель управления поверх существующего механизма загрузки.
- Добавлены отдельный пароль панели, подключение аккаунта, выбор доступных серверных папок и просмотр очереди.
- Появились прогресс файлов, пауза, повтор ошибок и настройка параллельных загрузок.
- Добавлены автоматическая контрольная проверка перед основной загрузкой и продолжение ранее запущенной операции после перезапуска.
- Сохранён CLI для работы без браузера.

## 0.3 — исправления подтверждения загрузки

- Ответ с `X-Valid-for: 0` принимается как допустимый.
- Для подтверждения безлимитной загрузки требуется точное значение `is_unlim_upload: true`.
- Подтверждение сохраняется до последующей проверки метаданных файла, чтобы его можно было учесть после прерывания операции.

Изменение OAuth-клиента на `cloud-win` относится к более раннему этапу 0.2 и не приписывается выпуску 0.3.
